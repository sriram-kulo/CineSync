# 🎬 CineSync Enterprise:

CineSync Enterprise is an autonomous multi-agent studio operating system built for the Summer Blockbuster Hackathon. It features Model Context Protocol (MCP) tool execution, multimodal script/PDF ingestion, self-correcting feedback loops, and enterprise telemetry.

## 🚀 Key Features
* **Multi-Agent Orchestration:** Sequentially coordinates Director, Department, Financial, and Auditor agents.
* **Model Context Protocol (MCP):** Securely queries remote studio inventory and asset databases via standardized tool-calling protocols.
* **Multimodal Ingestion:** Native parsing for raw script text, screenplay PDFs, and visual concept art.
* **Self-Correcting Executive Audit:** Automatically reviews and refines production sheets for budget overruns and safety risks.

## 🛠️ Tech Stack
* **Google Cloud & Gemini 2.5 Flash:** Powers all agent reasoning, multimodal analysis, and tool dispatching.
* **Replit:** Cloud hosting and deployment environment.
* **Streamlit:** High-performance executive studio dashboard.
